# Yard Week

Preview site for Yard Week, a weekly lawn-mowing company serving Lafayette, West Lafayette, and Tippecanoe County, Indiana.

Tagline: *Your yard. Every week.*

This is a static preview. The `yardweek.com` domain has not been purchased. Phone, email, and a live booking backend are still placeholders. Do not treat the form as a live order system.

Live preview: https://kagray17.github.io/yardweek-preview/
